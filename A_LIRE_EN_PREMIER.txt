───────────────────────────────────────────────────────────────────────
  1. CE QU'EST LE PROJET
───────────────────────────────────────────────────────────────────────

"Awakened" : une PWA (Progressive Web App) de fitness inspirée de Solo
Leveling. Elle mêle suivi d'entraînement réel et mécaniques de jeu RPG
(Failles, monstres, boss, arbre de compétences, stats, rangs E→SSS,
compagnons, équipement, narration en 57 événements).

Stack : JavaScript / HTML / CSS PUR (vanilla). AUCUN framework, aucun build
system. Le code tourne directement dans le navigateur.

L'utilisateur travaille SUR MOBILE et communique EN FRANÇAIS.
Réponds toujours en français.

───────────────────────────────────────────────────────────────────────
  9. PIÈGES CONNUS (à relire avant de toucher à ces zones)
───────────────────────────────────────────────────────────────────────

• `isNarrative` ≠ « Faille d'histoire ». C'est une protection
  anti-expiration portée AUSSI par les Failles compagnons, sous-boss et
  abysses. Pour identifier une vraie Faille d'histoire : `narrativeId`.
  Cette confusion a causé des bugs sur au moins 3 versions.

• renderGameTab() fait tab.innerHTML='' : tout ce qui est ajouté APRÈS
  (notamment #adventureContainer) doit être recréé et ancré sur un
  élément qui est bien ENFANT DIRECT de l'onglet. Déplacer un élément
  dans une carte casse ces ancres (v850).

• L'écran PRÉPAREZ-VOUS (#preparationView) vit dans l'onglet ENTRAÎNER.
  Toute séance lancée depuis un AUTRE onglet doit faire
  switchTab('workouts') avant showWorkoutPreparation (v848).

• Historique d'un profil : clé `profile_<id>_workoutHistory`
  (le profil ACTIF utilise aussi `workoutHistory` sans préfixe).
  Ce n'est PAS `workoutHistory_<id>` — erreur déjà commise (v816).

• Casse des noms d'exercices : les lookups d'images et de programmes
  sont sensibles à la casse. Vérifier le nom EXACT dans la base.

• Avant de créer un système, vérifier qu'il n'existe pas déjà : un
  sélecteur de douleur et un champ sexe ont été recréés en double.
